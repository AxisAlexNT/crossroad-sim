# Перекрёсток в Колпино — интерактивная модель

Приложение в одном HTML-файле, работает без интернета. Это инструмент для экспериментов и сравнения вариантов,
а не замер и не заключение. При создании использовались технологии ИИ-агентов, поэтому код, расчёты и тексты нужно проверять.

Что в нём есть:

- **Симуляция.** Машины, рейсовые автобусы и пешеходы, светофор с фазами и промтактами, правила уступания по ПДД,
  перестроение до сплошной линии, отказ от поворота, если перестроиться уже нельзя, нарушения ПДД у части рискованных водителей,
  заездные карманы и стоянка автобусов на остановках, столкновения в модели и перекрытие проезда после них.
- **Диагностика.** Взаимная блокировка с указанием секунды и фазы, отсутствие проезда при зелёном, падение средней скорости,
  статические проверки программы. Проверки разделены по источникам: действующие нормативы, то есть ПДД и ГОСТ Р 52289-2019 с изменениями № 1 и № 2,
  методические рекомендации Минтранса и проект стандарта о безопасности пешеходов. Нарушения положений проекта по умолчанию показываются
  как предупреждения, в настройках их можно сделать ошибками.
- **Редактор.** Подходы под любыми углами, полосы, разрешённые направления, пешеходный граф, светофоры с допсекциями слева и справа,
  фазы, остановки и маршруты. Черновик правится отдельно и переносится в симулятор одной кнопкой.
- **Графики и распределения.** Ожидание, проезды, очереди, скорость, опасные моменты, нарушения, гистограммы.
- **Подбор фаз.** NSGA-II или дифференциальная эволюция по выбранным критериям, графики с выбором осей, контурный график,
  таблица с сортировкой по нескольким столбцам. Все варианты считаются на одних и тех же потоках машин и пешеходов,
  лучшие перепроверяются на новых зёрнах и показываются со средним и 95 % доверительным интервалом.
  Есть опорная оценка цикла по формуле Вебстера и быстрый подбор с рекомендуемыми ограничениями.
- **Экспорт.** Модель в JSON, сессия в JSON, отчёт в PDF, схема в SVG со слоями для Inkscape.
- **Подложка OpenStreetMap.** Для Колпино встроена в файл в сжатом виде, около 28 КБ. По умолчанию выключена, включается в настройках и кнопкой 🗺 на карте.
  Для другого места загружается из выгрузки `.osm` или GeoJSON и хранится в модели.
- **Безопасность кода узлов.** Узлы без ручных правок работают встроенной логикой по параметрам. Код TypeScript, изменённый вручную,
  выполняется в изолированной песочнице QuickJS, скомпилированной в WebAssembly: без доступа к странице, сети, файлам и хранилищу браузера,
  с ограничением времени и памяти. При загрузке файла с таким кодом приложение спрашивает, запускать ли его.
- **Проверка загружаемых файлов.** Размер файла, число объектов, длина строк и диапазоны чисел ограничены,
  цвета принимаются только в виде `#RRGGBB`, всё из файла попадает в схему SVG только экранированным.

## Сборка на Ubuntu

```bash
# нужен Node.js 20 или новее, например из NodeSource или через nvm
node -v
npm -v

cd crossroad-sim
npm ci
npm run build
```

Результат — `dist/index.html`, один файл около 3,1 МБ со всеми библиотеками, шрифтами, песочницей и подложкой.
Он открывается двойным щелчком в Chrome, Firefox или Safari, сервер не нужен. Файл можно открыть и на телефоне.

Сборка рассчитана на смартфоны с 2020 года и встроенные браузеры приложений с поддержкой ECMAScript 2019:
Chrome и Android WebView 69 и новее, Safari на iOS 13 и новее, Firefox 68 и новее. Более новый синтаксис сборщик переписывает,
недостающие функции стандартной библиотеки добавляет `src/polyfills.ts`, для старых браузеров в стилях есть запасные варианты.
На медленных устройствах приложение само уменьшает время расчёта в кадре и рисует карту через кадр, а скрытые вкладки не перерисовываются.

Другие команды:

| Команда | Что делает |
|---|---|
| `npm run dev` | разработка с горячей перезагрузкой |
| `npm run typecheck` | проверка типов |
| `npm run build:check` | проверка типов и сборка |
| `npm run test` | проверка типов, движок и подбор фаз |
| `npm run test:engine` | прогон движка без браузера по всем предустановкам и шаблонам, проверка загрузки чужих файлов и песочницы |
| `npm run test:opt` | короткий прогон подбора фаз с перепроверкой |
| `npm run test:stall -- 7200 2` | долгие прогоны всех вариантов с несколькими зёрнами: нет ли остановок движения, которые не объясняются столкновениями |
| `npm run check:dist` | готовый файл не больше 5 МБ и разбирается как ECMAScript 2019, без внешних скриптов |
| `npm run osm -- путь/к/map.osm` | пересобрать встроенную подложку из выгрузки OpenStreetMap |
| `npm run licenses` | пересобрать файл `THIRD_PARTY_LICENSES.txt` с лицензиями сторонних компонентов |

Шрифт DejaVu Sans для PDF уже урезан до латиницы и кириллицы и лежит в `src/assets/fonts`.
Пересобрать его можно скриптом `scripts/subset-fonts.sh`, для него нужен пакет `fonttools` из pip.

## GitHub Actions

- `.github/workflows/ci.yml` — при каждом push и pull request: `npm ci`, проверка типов, тесты движка и подбора, сборка,
  проверка размера и синтаксиса. Готовый `index.html` прикладывается к запуску как артефакт `crossroad-sim-html`.
  Раз в неделю и вручную дополнительно идут долгие прогоны на остановки движения.
- `.github/workflows/release.yml` — по тегу вида `v1.0.0` файл собирается, проверяется и прикладывается к выпуску.
- `.github/workflows/pages.yml` — публикация на GitHub Pages. Включается в настройках репозитория: Pages → Source → GitHub Actions.
  По ссылке модель открывается в любом браузере, в том числе на телефоне, где HTML-файл из мессенджера не запускается.

## Подложка OpenStreetMap

Встроенная подложка для Колпино собрана скриптом `scripts/prepare-osm.ts` из выгрузки OpenStreetMap. Скрипт находит общую точку Оборонной и Тверской улиц,
оставляет область около 840 на 600 м, упрощает линии, оставляет только геометрию и нужные теги и сжимает результат.
Служебные поля выгрузки, например имена авторов правок, не сохраняются.

Для другого места:

1. На сайте openstreetmap.org выделите область вокруг перекрёстка и нажмите «Экспорт», получится файл `.osm`.
2. В приложении откройте «Настройки», раздел «Подложка OpenStreetMap», и загрузите файл.
3. При необходимости поверните и сдвиньте подложку, чтобы она совпала с дорогами модели.

Подложка сохраняется внутри модели и дальше работает без интернета. Подпись «© участники OpenStreetMap, лицензия ODbL» показывается на карте и в экспорте.

## Устройство

- `src/engine/` — движок без интерфейса: геометрия `network.ts`, светофор `signals.ts`, симуляция `sim.ts`,
  узлы по параметрам `nodes.ts`, песочница для кода `sandbox.ts`, проверки `checks.ts`, предустановки и шаблоны `presets.ts`,
  генераторы `generate.ts`, формат `model.ts` и пределы для загружаемых файлов `limits.ts`, подбор фаз `optimizer.ts`, `evaluate.ts`, `optWorker.ts`,
  формула Вебстера `webster.ts`, случайные числа `rng.ts`, источники и допущения `sources.ts`.
- `src/assets/osm/kolpino.ts` — встроенная сжатая подложка, `src/polyfills.ts` — недостающие функции для старых браузеров.
- `src/ui/` — интерфейс на Vue 3: карта `MapView.vue`, редактор `EditorTab.vue`, инспектор `Inspector.vue`, светофоры `PhaseEditor.vue`,
  графики на uPlot, гистограммы `Histogram.vue`, подложка `basemap.ts`, экспорт PDF `pdf.ts` и SVG `scene.ts`.
- `docs/model-format.md` и `schema/crossroad-model.schema.json` — описание формата модели.

### Код узлов

Узел без ручных правок хранится в файле модели только параметрами и работает встроенной логикой.
Код TypeScript, изменённый вручную, хранится в файле целиком и выполняется в песочнице, описанной выше.
Случайные числа нужно брать из `ctx.random()`, `ctx.uniform()`, `ctx.pick()` и `ctx.pickWeighted()`: тогда симуляция с одинаковым зерном повторяется,
а перемотка назад работает точно. В узле появления машин `ctx.random()` относится к моментам появления, а остальные функции — к свойствам машин,
у каждого подхода это отдельные потоки случайных чисел.

```ts
// Появление машин, вызывается каждый шаг симуляции
export function spawn(ctx: SpawnContext): NewVehicle[]
// Точка перестроения: номер полосы, 0 — у оси дороги
export function chooseLane(v: VehicleInfo, ctx: LaneContext): number
// Выезд: может ли машина в конце полосы покинуть модель на этом шаге
export function canExit(ctx: ExitContext): boolean
// Контроллер светофора в режиме «код»
export function nextPhase(ctx: ControllerContext): number
export function phaseDuration(ctx: ControllerContext, phaseIndex: number): number
```

Типы контекстов описаны в `src/engine/types.ts`.

## Допущения и ограничения

Геометрия оценена по картам, длительности фаз в предустановках условные, интенсивности условные.
Автобусные маршруты и интервалы взяты из открытых расписаний. Выявленные ограничения перечислены на вкладке «О модели», этот список может быть неполным.
Для выводов интенсивности нужно заменить подсчётом машин и пешеходов на месте.
